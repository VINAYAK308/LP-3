For this practical, the easiest implementation is a **Solidity smart contract deployed on the Sepolia Ethereum test network using Remix IDE and MetaMask**.

## Smart Contract: Bank Account

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract BankAccount {

    address public owner;
    uint256 private balance;

    constructor() {
        owner = msg.sender;
    }

    // Deposit Ether
    function deposit() public payable {
        require(msg.value > 0, "Deposit amount must be greater than 0");
        balance += msg.value;
    }

    // Withdraw Ether
    function withdraw(uint256 amount) public {
        require(msg.sender == owner, "Only account owner can withdraw");
        require(amount > 0, "Amount must be greater than 0");
        require(amount <= balance, "Insufficient balance");

        balance -= amount;
        payable(owner).transfer(amount);
    }

    // Show balance
    function showBalance() public view returns (uint256) {
        return balance;
    }
}
```

## Steps to Perform

### 1. Open Remix

Open:

[Remix IDE](https://remix.ethereum.org/?utm_source=chatgpt.com)

Create a new file:

```text
BankAccount.sol
```

Paste the Solidity code above.

---

### 2. Compile the Contract

1. Open **Solidity Compiler**.
2. Select compiler version `0.8.20` or a compatible `0.8.x` version.
3. Click **Compile BankAccount.sol**.

You should see a successful compilation message.

---

### 3. Connect MetaMask

1. Open MetaMask.
2. Select the **Sepolia** test network.
3. Make sure your wallet has some **Sepolia ETH** for gas fees.
4. Return to Remix.

---

### 4. Deploy the Contract

In Remix:

1. Open **Deploy & Run Transactions**.
2. Under **Environment**, select:

```text
Injected Provider - MetaMask
```

3. MetaMask will ask you to connect.
4. Select your account.
5. Make sure the network shown is **Sepolia**.
6. Click **Deploy**.
7. Confirm the transaction in MetaMask.

After deployment, the contract will appear under:

```text
Deployed Contracts
```

---

## 5. Deposit Money

In the deployed contract, you will see the `deposit` function.

Before clicking it, enter an amount in the **Value** field.

For example:

```text
Value: 0.01
Unit: ETH
```

Then click:

```text
deposit
```

Confirm the transaction in MetaMask.

The contract now holds:

```text
0.01 ETH
```

---

## 6. Show Balance

Click:

```text
showBalance
```

The contract will return the balance in **Wei**.

For example:

```text
10000000000000000
```

This corresponds to:

```text
0.01 ETH
```

because:

```text
1 ETH = 10^18 Wei
```

---

## 7. Withdraw Money

Enter the amount in **Wei** because the `withdraw()` function accepts `uint256`.

For example, to withdraw `0.005 ETH`:

```text
5000000000000000
```

Then click:

```text
withdraw
```

Confirm the transaction in MetaMask.

The contract balance becomes:

```text
0.005 ETH
```

and `0.005 ETH` is transferred back to the owner's wallet.

---

## Important Functions

| Function           | Purpose                                       |
| ------------------ | --------------------------------------------- |
| `deposit()`        | Deposits ETH into the smart contract          |
| `withdraw(amount)` | Withdraws ETH from the contract               |
| `showBalance()`    | Displays the contract's ETH balance           |
| `owner`            | Stores the address that deployed the contract |

### Flow

```text
              BankAccount Smart Contract
                       |
          ┌────────────┼────────────┐
          ↓            ↓            ↓
       Deposit      Withdraw    Show Balance
          ↓            ↓            ↓
       ETH →       ETH → Owner   Balance
       Contract
```
