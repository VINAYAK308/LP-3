## Steps to Perform the Practical

### Step 1: Install MetaMask

1. Open the official MetaMask website.
2. Install the MetaMask browser extension for Chrome.
3. Add the extension to Chrome.
4. Open MetaMask.

Use only the official MetaMask website/extension; fake wallet applications are a common security risk. ([MetaMask Help Center][2])

[Official MetaMask Website](https://metamask.io/?utm_source=chatgpt.com)

---

### Step 2: Create a New Wallet

1. Open MetaMask.
2. Select **Create a new wallet**.
3. Set a strong password.
4. MetaMask will provide a **Secret Recovery Phrase**.
5. Write the recovery phrase down and store it securely offline.
6. Confirm the recovery phrase when MetaMask asks.
7. Your wallet will now be created.

The Secret Recovery Phrase gives access to the wallet, so **never share it with anyone**, including someone claiming to be MetaMask support. ([MetaMask Help Center][3])

---

### Step 3: Copy Your Wallet Address

After creating the wallet:

1. Open MetaMask.
2. Select your account.
3. Copy the **0x...** wallet address.

Example:

```text
0x1234...ABCD
```

This is your **public Ethereum address**.

Do **not** confuse it with your private key or Secret Recovery Phrase.

---

### Step 4: Enable the Sepolia Test Network

1. Open MetaMask.
2. Open the network selector.
3. Enable/display **test networks** if necessary.
4. Select **Sepolia**.

MetaMask supports Sepolia directly, and its documentation explains how to enable testnets from the wallet settings. ([MetaMask Help Center][4])

---

### Step 5: Get Test ETH

You need Sepolia ETH to perform the transaction.

1. Open the MetaMask Developer Sepolia faucet.
2. Connect your MetaMask wallet.
3. Select your Sepolia account/address.
4. Request test ETH.
5. Wait for the transaction.
6. Check your MetaMask balance.

MetaMask provides a Sepolia faucet specifically for obtaining test ETH, and Ethereum also lists multiple Sepolia faucets. ([MetaMask Help Center][5])

**Important:** Sepolia ETH is test currency and is not real money. ([MetaMask Help Center][5])

---

### Step 6: Create a Second Wallet

For demonstrating a transaction, create another account.

In MetaMask:

1. Click the account selector.
2. Select **Add account**.
3. Create another account.
4. Copy its public address.

Now you have:

```text
Account 1 → Sender
Account 2 → Receiver
```

You can also use a classmate's Sepolia wallet address if your instructor wants two separate wallets.

---

### Step 7: Send ETH

From **Account 1**:

1. Select the **Sepolia** network.
2. Click **Send**.
3. Enter the public address of **Account 2**.
4. Enter a small amount of test ETH, for example:

```text
0.001 ETH
```

5. Click **Continue**.
6. Review:

   * Recipient address
   * Amount
   * Network
   * Estimated network fee
7. Click **Confirm**.

MetaMask's current transaction flow is essentially **Send → select network/token → enter recipient → enter amount → review fee → Confirm**. ([MetaMask Help Center][6])

---

### Step 8: Check the Transaction

After confirming:

1. Open MetaMask's **Activity** section.
2. Find the transaction.
3. Click the transaction.
4. Copy the **Transaction Hash / Transaction ID**.

It will look similar to:

```text
0x8a7f...93bc
```

The transaction hash uniquely identifies the transaction on the blockchain.

---

### Step 9: Verify the Transaction on a Block Explorer

Open a Sepolia block explorer.

Search using your transaction hash.

You should be able to see information such as:

```text
Transaction Hash
From
To
Value
Transaction Fee
Block
Status
Timestamp
```

This demonstrates that the transaction has been recorded on the public blockchain.

---

### Step 10: Verify Receiver Balance

Switch to **Account 2** in MetaMask.

You should see the received Sepolia ETH reflected in the balance.

So your practical flow is:

```text
Create MetaMask Wallet
        ↓
Enable Sepolia Testnet
        ↓
Get Test ETH from Faucet
        ↓
Create Second Account
        ↓
Copy Receiver Address
        ↓
Send Test ETH
        ↓
Confirm Transaction
        ↓
Get Transaction Hash
        ↓
Verify on Block Explorer
        ↓
Check Receiver Balance
```
